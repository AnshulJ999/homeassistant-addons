# Home Assistant Addons

A collection of personal Home Assistant addons.

## 📦 Available Addons

### [SyncLyrics](./synclyrics)

A feature-rich application that displays synchronized lyrics for your currently playing music. Fetches real-time lyrics from multiple providers and displays them in a beautiful web interface accessible from any device on your network.

**Key Features:**
- 🎵 **5 Lyrics Providers:** Spotify, LRCLib, Musixmatch, NetEase, QQ Music
- 🎨 **Visual Modes:** Sharp, Soft, and Blur album art backgrounds
- 🎤 **Audio Recognition:** Shazam-powered song identification
- 🎛️ **Playback Controls:** Play/pause, skip, like, queue display
- 📱 **Responsive UI:** Minimal mode for embedding/tablets

➡️ [View SyncLyrics Documentation](./synclyrics/README.md)

### [KopiaLens](./kopialens)

Find what's bloating your Kopia backups and get the space back. KopiaLens shows the real size of everything in a Kopia repository, finds the files you never meant to keep, and can run your backups too. Opens in the Home Assistant sidebar.

➡️ [KopiaLens in Home Assistant](https://kopialens.com/docs/home-assistant) · [kopialens.com](https://kopialens.com)
